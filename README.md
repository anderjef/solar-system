# Solar System

Solar System generates a random solar-system animation.  
Start date: 2019-09-16

## Dependencies

- [Processing 4.0 beta 1](https://processing.org/download)
  - PeasyCam library

## Installation

- Open Processing (IDE).
- Open any of the `*.pde` files with Processing (IDE).

## Usage

1. Launch the program using Processing (IDE).
1. Click and drag the display to rotate the camera. Scroll to zoom. Press the spacebar to toggle whether the space background is redrawn each frame.

## Deployment

Exporting the application requires copying [starTexture.jpg](starTexture.jpg) into the executable's folder.
